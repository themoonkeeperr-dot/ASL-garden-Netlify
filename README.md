# ASL Garden — Netlify visual build

This build is designed for Netlify and keeps the learning experience visual-first.

- Alphabet: clear ASL handshape image for every letter, plus a looping embedded sign example where a verified reusable ASL Signbank clip is available.
- Games: sign video first; answer choices are English words only; no voice and no fingerspelling.
- Translator: sentence input with visual sign clips for mapped terms and an embedded visual fallback for other terms; no outbound sign links on each card.
- Food: larger fruits/vegetables collection; verified animated clips are embedded without controls.
- Numbers and Stories: kept as the visual versions from the previous build.
- No Start ASL or ASL Search media is used.

ASL Signbank media is used according to its published CC BY-NC-SA 4.0 terms and is attributed globally in the footer rather than under every sign.

## Latest visual updates
- Alphabet layout follows the original Replit ASL Garden card composition: handshape on the left, animated sign example on the right, then `A → Word` underneath.
- The alphabet no longer embeds Lifeprint images or Start ASL/ASL Search media; reusable ASL Signbank clips are used where verified/available, with a neutral placeholder elsewhere.
- Food cards no longer fall back to Sign ASL embeds. They use the reusable ASL Signbank clips available in the project and a local placeholder when a reusable clip is not yet mapped.
- Translator results now place the animated sign clip beside the English word and make the clip substantially larger.
